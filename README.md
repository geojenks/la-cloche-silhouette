# La Cloche Silhouette — Killarney PP, August 2026

Interactive trip map of a six-day clockwise loop of the La Cloche Silhouette
Trail (77.5 km with the Silver Peak side trip). Day-coloured route, linked
map/elevation scrubbers, and hotpoints for photos, videos, and voice notes
recorded on the trail.

**Base map © [Maps by Jeff](https://digital.mapsbyjeff.com/)** — buy his La Cloche map at the Outfitters near base camp. It's essential.
